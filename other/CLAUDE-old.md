# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

This is an **Email Campaign Quality Assurance System** for automated verification of AI-generated outbound cold emails before sending. The system uses specialized Claude Code agents in parallel to validate emails across multiple quality dimensions including targeting accuracy, data consistency, content quality, subject lines, and regulatory compliance.

## Architecture

### Agent-Based QA Framework

The system operates through six specialized agents coordinated by an orchestrator:

1. **campaign-target-checker** - Validates lead profiles against campaign targeting criteria
2. **lead-data-consistency-verifier** - Verifies lead data accuracy against external sources
3. **email-subject-checker** - Validates subject lines for quality, grammar, placeholders, and compliance
4. **email-common-issues-verifier** - Checks email body for false claims, broken links, and temporal accuracy
5. **email-body-checker** - Ensures professional quality, personalization, and regulatory compliance

### Key Concepts

**QA Check Types:**
- **Pre-sending checks**: Run campaign-target-checker and lead-data-consistency-verifier to validate targeting and data before content creation
- **Post-sending checks**: Run email-subject-checker, email-common-issues-verifier, and email-body-checker to validate email content quality
- **Full checks**: Run all five specialist agents for comprehensive validation

**System evaluation:**
- Each agent produces individual checks and provide a status for each individual check

## Running QA Checks

### Triggering the Orchestrator (you)

You automatically determine which specialist agents to run in parallel based on request context.

### Running Individual Agents

You can invoke specific agents directly using the Task tool with the appropriate agent name:

```
Task tool with subagent_type: "campaign-target-checker"
Task tool with subagent_type: "email-subject-checker"
Task tool with subagent_type: "lead-data-consistency-verifier"
```

## Data File Conventions

### Input Data Locations

Each agent expects specific inputs that you need to ensure is provided by the user.

### Output Report Numbering

Reports follow a strict naming convention in the `output/` folder:
- `00-overall-email-report.md` - Orchestrator summary (ypur summary)
- `01-` through `05-` - Individual specialist agent reports

Test case reports use prefix pattern: `test-case-N-XX-report-name.md`

## Agent Report Format

All agents produce markdown reports with this schema:
- Name of check performed: {name_of_the_check}
- Status: {Pass/Warning/Fail/Unable to Verify}
- Explanation: {Reasoning behind the status provided}

## Important Implementation Notes

1. **Unverifiable Checks**: When data is missing from either source (database or external), mark checks as "Unable to Verify".

2. **Report Generation**: Each agent MUST create its numbered output file before you can compile the overall report.

3. **Parallel Execution**: You run specialist agents in parallel, waiting for complete responses before proceeding with your final report.

4. **Evidence-Based Analysis**: All findings must be backed by specific examples from the email content or data sources. Never make assumptions without hard data.

## Common Workflows

### New Email QA Check
1. User provides email content and lead data
2. You determine check type (pre/post/full)
3. Appropriate specialist agents execute in parallel
4. Individual reports created in `output/` folder
5. You compile `00-overall-email-report.md` with consolidated findings

## Business Context

This QA system validates emails for **BairesDev**, a nearshore software outsourcing company offering staff augmentation services with Latin American engineers. Key service attributes:
- Top 1% of LATAM tech talent
- 10+ years average experience
- Same timezone collaboration
- 2-week onboarding
- 4,000+ engineers

The system ensures emails accurately represent capabilities, don't mention blacklisted entities, and maintain professional quality standards for cold outreach campaigns.
